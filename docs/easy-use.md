# 一条命令使用 justbuild

更新：2026-10-26。当前提供中文终端向导，不需要桌面 CAD，不必激活 Python 环境。网页用于审阅三维结果和明确打印版本。

## 当前电脑直接试

新开终端，输入：

```bash
justbuild
```

会显示：

```text
justbuild · 板卡外壳助手
提交板卡 → 确认接口 → 查看外壳 → 审阅后打印

1  新建外壳：拖入 STEP 文件，填写需求
2  查看已有设计：直接打开三维结果
3  检查 A1 连接：不会启动打印
4  运行合成板自检：不使用打印机
0  退出
```

第一次试用选择 `2`，再选“真实 V821 · 全接口维护窗草案”。这是已有真实板卡 STEP 生成的结果，可立即查看三维模型、透明、剖切、孔位和报告，不会重复建模或改变旧版本的审阅限制。

制作新板时选择 `1`，把 STEP/STP 文件从文件管理器拖进终端，回车后输入要求，例如“上下盖螺丝固定，USB/卡槽/按钮可正常操作，安装孔严格依照原板”。直接回车使用屏幕列出的默认需求。程序检查文件，复用或启动本机服务，整理待确认提案并输出一次性本机管理链接；有桌面环境时请求浏览器打开，SSH/无显示环境仍可复制链接。

向导不会要求手工编辑 JSON，不会自动确认尚未审阅的孔位或接口。当前通用自然语言接口语义识别与修复循环尚未集成，保存要求不等于自动识别完所有接口。真实未知接口、插头、按钮行程与线缆约束仍需确认。

## 文件也能直接拖到命令后面

```bash
justbuild /absolute/path/board.step
```

路径支持空格、Shell 引号/拖拽转义以及本地 `file://` URI。一次一个 STEP/STP，最大 100 MiB；路径文字不会作为命令执行。

已有明确要求时可以一次提交：

```bash
justbuild /absolute/path/board.step \
  --requirements '上下盖、螺丝固定；保留原孔位；USB、卡槽、按钮需要正常使用'
```

云服务器或 SSH 不打开本地浏览器：

```bash
justbuild easy /absolute/path/board.step \
  --requirements '你的要求' --no-open
```

`127.0.0.1` 仍指运行服务的机器，不能把它直接当公网链接。SSH 可通过自己的端口转发访问本机审阅；公网多人服务、账户隔离和 A1 云跨网发印仍待实现。向导默认只在回环地址启动服务，不会监听公网。

## 没有全局命令时

这台电脑已在 `~/.local/bin/justbuild` 安装快捷入口，只调用项目内的启动脚本，不复制打印机凭据或改变 Shell 配置。源码包解压后，也可直接运行项目根目录的：

```bash
./justbuild
```

首次没有专用运行环境时，启动器调用既有 `scripts/bootstrap.sh` 安装无界面 Python 依赖（含可选 LAN 依赖）。不会安装桌面 CAD。实际切片仍需要另行配置官方切片器；首次全新机器安装尚未验收。项目在移动硬盘上时，运行环境保存在支持虚拟环境的用户缓存目录。

本机已有兼容服务时，向导读取严格回环限制的 `/api/local/workspace`，复用它实际的数据目录，避免“生成了任务但链接看不到”。未启动服务时才新建后台服务；端口已有其它或旧版本服务时给出提示，不会杀掉或覆盖它。后台日志位于用户状态目录，权限0600；终端不打印切片器配置、访问码或完整序列号。

菜单 `3` 仅做设备身份/固件/证书和状态的只读检查。没有配对时打开本机配对页；连接成功或设备忙碌均不会上传文件、启动打印、加热或改设备参数。

打印必须继续经过具体版本审阅、明确操作和原有散列/幂等限制。本轮新增的是易用入口；没有通过向导发起实际打印，不能把菜单运行、网页打开或连接通过当作实物验收。
