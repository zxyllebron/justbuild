# 迁移、使用入口与复现边界

更新：2026-10-26。justbuild 0.1.0 当前是独立 Python 框架：CLI、HTTP API、网页审阅与磁盘任务记录。仓库尚未提供 `SKILL.md`；Codex/Claude 可调用这些入口，但可选 `providers.py` 包装函数尚未接成完整的自然语言自动设计循环。Skill 可以作为安装与调用说明的一层封装，几何计算、验证和打印幂等状态仍由框架执行。

## 别人在另一台机器怎么用

当前实际运行基线为 Linux x86_64 / CPython 3.12.3 / CadQuery 2.6.1 / OCP 7.8.1.1.post1。源码声明 Python 3.11+；本机完整依赖组合与 Windows/macOS、干净容器尚未跨机验收。当前工作环境含系统/site 包，因此不能把它直接当成经验证的通用锁文件。先在独立环境安装，不复制原工作机虚拟环境或打印机配置。

在解压后的源码目录执行（虚拟环境放到支持符号链接的本地文件系统）：

```bash
python3.12 -m venv "$HOME/.cache/justbuild-portable/venv"
. "$HOME/.cache/justbuild-portable/venv/bin/activate"
python -m pip install '.[lan]'
python -m pip check
justbuild doctor
justbuild self-test --out ./selftest-001
JUSTBUILD_ENABLE_LOCAL_PRINTER_SETUP=1 JUSTBUILD_ENABLE_LAN_PRINTING=1 \
  justbuild serve --host 127.0.0.1 --port 18765
```

已有的非空 `selftest-001` 不会被覆盖；再次测试请换新目录。上述安装命令是迁移使用步骤，本次尚未在全新机器执行该安装组合。`doctor` 只检查元数据/文件，不冒充 CAD 运行；`self-test` 才会实际生成与独立核验合成板。见 [doctor.md](doctor.md)、[selfcheck.md](selfcheck.md)。

打开 `http://127.0.0.1:18765`。该地址只指向运行服务的本机。若服务在云服务器上，浏览器所在电脑的 `127.0.0.1` 不会自动连到服务器。本版不是已上线的公网多用户服务；不要直接把本机配对和发印 API 公开暴露。

每个使用者完成一次本地 `/printer-setup` 配对，填写自己 A1 屏幕上的 IP、序列号、固件与隐藏访问码，并确认设备和证书。之后可执行 `justbuild printer check` 做只读连接检查。不能将原作者私有配置复制给他人；网络或证书变更需重新核对。LAN 方案要求服务机器能实际访问打印机的局域网服务；当前先验收同网方案，跨网云发印仍未实现。

可在网页上传 STEP 和独立用户要求，也可让本机 AI 执行：

```bash
justbuild intake /absolute/path/board.step \
  --requirements '上下盖螺丝固定；USB、卡槽、按钮可正常操作；保留原PCB孔位'
```

命令输出审阅链接与待确认提案，不会直接发印。`local_owner_url` 是绑定本机会话的一次性管理链接，不能当作公共分享链接。确认 PCB、安装孔、接口开口、连接器/插头/按钮操作包络和制造参数后，再由网页确认操作或 `justbuild run confirmed-request.json` 完成生成、检查、可选切片。自然语言要求会独立保存；它尚不能保证自动识别每个任意 STEP 中的接口语义。

## 切片与打印还需要什么

CAD 核心不需要 SolidWorks 等桌面软件。真实 A1 切片使用另行安装的官方 Bambu Studio CLI 二进制、资源与明确打印配置；这些可选组件不在开源包中。可以无显示运行切片，无需保持 Studio 界面登录。所需环境配置、二进制固定散列及本机已验证样例见 [README](../README.md#配置已安装的切片器)。`doctor` 的切片配置检查不执行切片，实际结果以任务中的非模拟切片和有效配置回读为准。

独立 LAN 适配器不依赖 Studio 账号会话。生成完成后，需要按产品约定审阅具体版本，再显式启动打印；打印准备清单绑定具体切片、设备和设置。旧版本的授权不能被拿来打印后来改过的外壳。设备空闲、上传、接收、启动回执和物理完成分别记录；未知提交不自动重试。原始 V821 新版仍有 hold，本轮未上传或启动打印。

## 能保证相同效果到哪一层

| 层次 | 复现条件 | 实际验收方法与边界 |
| --- | --- | --- |
| 软件安装与运行 | 相同源码版本、受控 Python 与依赖、包内资源齐全 | `doctor` + `pip check` + 真实 `self-test`。元数据一致不等于原生库已可用，尚未完成新机器/容器安装验收。 |
| 同一块板的几何 | 相同原始 STEP 散列、相同已确认数值请求、CadQuery/OCP 与相关几何参数 | 比较实际 BRep 实体、孔轴、尺寸、净距和独立检查语义。任务 ID、路径、时间和 STEP/GLB 文件字节可不同；单个任务的精确散列仍用于来源和打印审批绑定。迁移路径后重新生成/确认。 |
| 自然语言理解 | 相同模型、提示和完整器件/操作约束仍可能产生不同提案 | 不承诺“相同一句话得到同一个可装配设计”。目前完整模型驱动设计/修复循环未接通；确认后的数值请求才是机械设计依据。 |
| 同切片结果 | 相同切片器二进制散列/版本、资源继承来源、机器/喷嘴/材料/工艺及摆放 | 回读真实 G-code、有效配置与 ZIP CRC；不以基础安装成功或模拟测试替代实际切片。 |
| 实物可装配与可使用 | 材料、校准、公差、打印方向、螺丝、真实插头/线缆和工作条件均纳入验收 | 几何检查不能单独保证 FDM 孔径、强度、散热、RF、按钮/锁扣真实行程或长期工作。仍需首件装配验证。 |

`self-test` 使用明确的 80×55×1.6 mm 合成板、四个孔与合成元件，验证本机 CAD 后端和独立检查链。它不联网、不调用模型、不运行切片器、不读取打印机资料、不打印。报告包含量化几何语义指纹，可在重复运行或另一台机器上比较；它不要求导出文件字节散列一致，不等于任意真实板卡都能自动适配。

V821 的现有实板结果使用原始 543 个实体和专门审阅的 21 个命名组件。移植到另一块板时，必须重新确定其接口、维修开口、按钮/卡槽操作、安装基准与线缆空间；不能直接复用 V821 的语义标注来宣称同样效果。

部署目标仍是“提交文件和要求 → 得到可查看链接 → 确认机械方案 → 自动生成/核验/切片 → 审阅后明确发印”。当前已实现的 CLI/API 与验证链可重用；通用模型规划循环、公网多人隔离、云端跨网发印和首件实物验收仍是后续工作。
